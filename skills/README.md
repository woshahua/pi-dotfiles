# Skills

本目录只保存可验证的来源元数据，不复制第三方 skill 源码。

- Pi 扩展包附带的 skills 已由 `pi/settings.json` 声明。
- Omarchy 提供的 `omarchy` 与 `diagnose-crash` 继续使用系统路径。
- 单独安装且来源已知的 skill 记录在 `external-skills.json`。
- `~/.agents/skills`、`~/.codex/skills` 中来源或许可不明确的内容不会自动发布。

若要把自编 skill 加入此仓库，请在 `skills/custom/<name>/SKILL.md` 下维护，并在提交前检查其中没有个人路径、凭据或私有项目内容。
